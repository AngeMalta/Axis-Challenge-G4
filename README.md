# ChargeSpot Hub

Construa um web/mobile, no qual é para carregador elétrico circular nos comercios (linha HCA G2), quero que você construa uma web/mobile no qual o comerciante irá poder ter controle do carregador cadastrado no ambiente dele, quanto de energia será consumido, consumo por minuto, um dashboard mostrando o lucro dele.

Para o user quero que você crie uma interface no qual o irá aparecer um mapa, mostrando as fotos dos carregadores mais proximos, junto com um mapa, e irá mostrar para o user estimativa de tempo de recarga, se está ocupado, preço de recarga.

OBS: O nome da web deve ser AXIS, na interface quero padrões de cores vermelhos, mas de preferência o fundo preto ou branco (coloque a opção do usuario/comerciante escolher se quer tema claro ou escuro)

Quero que você coloque tudo funcional, além da opção de alterar foto de perfil, nome, resumindo opção do usuario ou comerciante ser livre para customizar seu perfil.

Na parte do comerciante, quero que você adicione a função de editar o carregador, preço e tudo, além de adicionar mais opções necessárias para o comerciante utilizar.

Para o user, quero que quando ele clicar no carregador, aparecer imagens do carregador, descrição, preço, distância, quantos minutos vai demorar para chegar, e se possivel colocar a rota para ele, e se possivel acrescentar coisas que pode melhorar a experiência do usuario e deixar mais fácil dele utilizar.

Relatórios Comerciais: Crie filtros por período, exportação CSV e visão detalhada de receita por carregador

Sessão Ao Vivo: Mostre potência, energia acumulada, fila e tempo restante atualizados durante a recarga
